How it works

Bring a Dockerfile and a GitHub repo. No platform YAML.

  1. Dockerfile in repo — we build rootless in-cluster.
  2. Install the GitHub App — every push queues a deploy.
  3. Live URL — production on main, preview per commit, custom domain optional.

Included

  • HTTPS on every deploy
  • Postgres per project
  • Env vars & secrets
  • Live build logs
  • CPU / memory telemetry
  • Rollback to any commit
