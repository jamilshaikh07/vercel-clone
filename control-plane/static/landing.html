How it works

Three steps to production

No YAML ceremony. Bring a Dockerfile (or a static site) and a GitHub repo.

01

Add a Dockerfile

Most frameworks fit in a few lines. We build rootless in-cluster with Kaniko.

02

Connect GitHub

Install the Spinup GitHub App on your repo. Every push queues a build automatically.

03

Get your URL

Production tracks main. Each commit gets its own preview hostname. Attach your own domain when you're ready.
