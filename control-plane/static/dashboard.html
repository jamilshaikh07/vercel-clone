    About Spinup

    Push to GitHub.
    Get a live URL.

    Spinup is a self-hosted deployment platform — a Vercel-style experience running on a bare-metal Kubernetes homelab in India.

    Why this exists

    Built so students and indie builders can ship real projects without Vercel-scale bills. The infrastructure is mine; the goal is to make “git push → HTTPS URL” accessible to people who would otherwise stall on cost or complexity.

    Spinup started as a homelab experiment: could a two-node Talos cluster reliably turn a GitHub push into a running app with TLS, logs, env vars, and Postgres — with no human in the loop? The answer turned out to be yes, and this dashboard is the control plane for that pipeline.

    How it works

    • Connect a repo — install the Spinup GitHub App on a repository you own.
    • Push code — every push queues a build. Kaniko builds your Dockerfile (or auto-detects a static/Node app) inside the cluster.
    • Go live — a Deployment, Service, and IngressRoute appear automatically. Production branch deploys get a stable *.spinup.in alias; every commit gets its own preview URL.
    • Configure — env vars, optional Postgres, custom domains, and rollback from this dashboard.

    What's included today

    • HTTPS via Cloudflare Tunnel (no cert-manager juggling)
    • Per-project Postgres on a shared CloudNativePG cluster
    • Build logs, deployment history, instant rollback
    • Ops monitoring — pod resources and edge HTTP counts from Traefik (not visitor analytics)
    • Custom domain verification (TXT + CNAME)

    What we're not (yet)

    Spinup is invite-only while the cluster scales. There's no multi-region, no team RBAC, and no managed registry SLA — images live on an in-cluster registry. Treat it as production-capable for side projects and learning, not as a replacement for Vercel at enterprise scale.

    Danger zone

    Permanently delete this app from Spinup. Deployments, domains, and env vars are removed. Your GitHub repo stays connected until you revoke the Spinup App.

    Delete app

    This permanently removes the app from Spinup — deployments, custom domains, env vars, and live URLs.

    • Running pods and IngressRoutes are torn down immediately.
    • Your GitHub repo is not uninstalled — revoke access in GitHub if needed.
